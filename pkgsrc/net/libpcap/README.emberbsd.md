# Shared libpcap recipe

This recipe and its complete patch set are based on NetBSD pkgsrc
`net/libpcap` at revision `b0e04e699d3f0acfdee26ddf3b5796596fd23655`.
It selects upstream libpcap 1.11.0. The same prepared source is used by the
native EmberBSD producer, which retains its own ABI and installation rules.
