# Web App Manager

Web App Manager creates and edits desktop launchers for websites. Start `webapp-manager` from the applications menu or the installed package prefix. Select Ember Browser, enter a name and an HTTP(S) address, and choose private mode when needed. Removing an Ember Browser web app removes its Browser-owned normal and private profiles; close the app before clearing its data. Browser launch and cleanup semantics are documented in [Browser WebApp contract](../blanc/README.webapps.md).

The owner test `files/native-qa.py` exercises a real target GTK/Gio installation with an isolated temporary HOME. Run it with the installed target Python and `--prefix <installed-prefix> --temp-home <new-absolute-directory>`. It creates and leaves that test directory for inspection; it requires an active desktop session and installed dependencies. Run only in a controlled session. Native acceptance of 1.4.7nb1 passed on EmberBSD amd64: GTK/XApp widgets, compiled GSettings schema, icon lookup, visible validation, create/edit/delete, and exact Gio argv with Cyrillic and special characters. The fixture uses an executable recorder for the Browser boundary; actual Browser navigation, isolation and profile cleanup are checked separately by the Browser native test. A refused clear preserves the launcher.
