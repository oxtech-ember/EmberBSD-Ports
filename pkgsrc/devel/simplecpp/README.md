# Common SimpleCpp 1.10.2

The source is the [upstream 1.10.2 release](https://github.com/cppcheck-opensource/simplecpp/releases/tag/1.10.2).
Tag commit: `920637c5bdb57c5d9064dd4bb846b5719ec7f626`, released 2026-11-21.
Archive SHA256: `709fed69c459d8405b472dbfe8e7118e1767c7d6970aef49fdb05392e599c24a`.

The common recipe adds installation to upstream CMake.
It preserves the CLI and complete CMake unit-test executable.
Both link the installed-library target instead of separate implementation objects.
SimpleCpp 1.10 extends the public token and macro-usage records. Cppcheck 2.22.0 rebuilds with the new declarations.
The header adds only the installed ABI check before its standard-library includes.
The library exports `simplecpp::simplecpp` and the upstream Windows import/export definitions.
Its ABI series is `1.10`; the CMake version contract requires an exact release.
Review ABI and rebuild consumers before changing this version.

The common package selects `SIMPLECPP_GLIBCXX_DEBUG=ON` for the checked libstdc++ container ABI.
The exported target propagates `_GLIBCXX_DEBUG` to every consumer, independent of its build type.
Cppcheck keeps its Debug diagnostics and propagates this requirement through `cppcheck-core` to its dependents.
The installed `simplecpp-abi.h` rejects a mismatched mode; it never defines or undefines the ABI macro.
The ABI header is generated by the package's CMake producer and installed beside `simplecpp.h`.

Run `tests/abi_contract.py --source /absolute/prepared/simplecpp` for source wiring and three negative controls.
`tests/abi/` is a separate CMake project for the selected SDK toolchain and installed package prefix.
It must link a `TokenList` consumer across the `std::vector<std::string>` API boundary.
It must also reject an intentionally removed ABI macro with the exact header diagnostic.
Those compile/link checks are prepared but have not run. They do not execute target programs.

Cppcheck is the only SimpleCpp library consumer found in the Ports recipes.
Chocolate Doom's `man/simplecpp` is an unrelated Python documentation script.

The upstream license remains BSD Zero Clause and is installed with the package.
The packaging patch is AI-assisted EmberBSD work.
The current source gate is `../cppcheck/tests/dependencies.py`.
It checks exact archive hashes, patch replay, upstream provider identity and consumer imports.

Native and target compilation, installed CLI/library consumers, memory checks and package lifecycle remain pending.
The ordinary `test` target retains the complete upstream CMake unit suite.
Upstream also provides pytest integration and GCC/Clang comparison suites.
Those files remain unchanged; they need separate tool admission and are not reported as executed.
