# NNG source provenance

The NNG 2.1.0 release was built from tag `v2.1.0`, commit `0912dcbd63f2f44324fa974e9fc9695c7621abb9`. Its source is distributed under the MIT license. [Upstream release](https://github.com/nanomsg/nng/releases/tag/v2.1.0)

The default package installs the upstream version 2.1 HTML reference published at commit `8935ae95671151abc53e4ae81e330789b639781c`. The manual pages are generated from the Markdown chapters and symbol index in the source release. Archive names, cryptographic hashes and sizes are recorded in the package.
