# Current American English dictionary

Use the official ESDB/SCOWL Hunspell dictionary release 2026.02.25.
The package version uses the existing compact date convention: 20260225.
This keeps package upgrades monotonic from the former 20060207 package.
The default size 60 dictionary is the upstream recommendation.

Source: <https://wordlist.aspell.net/dicts/>
Archive: <https://github.com/en-wl/wordlist/releases/download/rel-2026.02.25/hunspell-en_US-2026.02.25.zip>

SCOWL permission notice, contributor credits and Geoff Kuenning's affix
license. Do not replace these distinct terms with a generic license text.
This recipe retains the stock license metadata gap; the installed README
contains the complete redistribution terms.
